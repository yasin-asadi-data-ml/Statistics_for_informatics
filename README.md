# 📊 Statistics for Informatics


**Purpose:** A hands-on, code-first laboratory for learning fundamental Statistics, Data Analysis, and Machine Learning using Python and Jupyter Notebooks.

---

## 🎯 About This Lab

This repository is a structured learning journey through the core statistical concepts every Data Scientist and ML practitioner needs to know. Instead of just reading theory, you will **write code**, **visualize data**, and **run statistical tests** on real-world datasets.

By the end of this lab, you will be able to:
- Understand and apply Descriptive & Inferential Statistics.
- Perform Hypothesis Testing (t-tests, ANOVA, Chi-Square).
- Build and interpret Linear & Logistic Regression models.
- Use Python's core data science stack (Pandas, NumPy, SciPy, Matplotlib, Seaborn).

---

## 🗺️ Lab Curriculum

| Notebook | Topic | Key Skills |
| :--- | :--- | :--- |
| `01_descriptive_stats.ipynb` | Descriptive Statistics | Mean, Median, Mode, Variance, STD, Skewness |
| `02_probability_distributions.ipynb` | Probability Distributions | Normal, Binomial, Poisson distributions |
| `03_clt_sampling.ipynb` | Central Limit Theorem | Sampling distributions, Standard Error |
| `04_hypothesis_testing.ipynb` | Hypothesis Testing | Null/Alternative hypothesis, P-values, Significance |
| `05_ttest_anova.ipynb` | T-Tests & ANOVA | Comparing group means (1-sample, 2-sample, paired) |
| `06_chi_square.ipynb` | Chi-Square Tests | Categorical data analysis, Goodness-of-fit |
| `07_correlation.ipynb` | Correlation | Pearson's r, Spearman's rank, Covariance |
| `08_linear_regression_simple.ipynb` | Simple Linear Regression | Slope, Intercept, R-squared, Residuals |
| `09_linear_regression_multiple.ipynb` | Multiple Linear Regression | Multi-collinearity, Adjusted R-squared |
| `10_logistic_regression.ipynb` | Logistic Regression | Classification, Odds ratios, Confusion matrices |
| `11_bootstrapping_cv.ipynb` | Resampling Methods | Bootstrapping, Cross-Validation |
| `12_bayesian_inference.ipynb` | Bayesian Basics | Prior, Likelihood, Posterior distribution |
